# DKoder landing-page redesign

A responsive front-end redesign based on the supplied DKoder landing-page capture and Tech Hike reference PDF. It keeps the visible content families and navigation concepts while improving hierarchy, layout, visual consistency, responsive behavior, and interactions.

## Run locally
Open `index.html` in a modern browser. No build step is required. Internet access is only needed for Google Fonts; system fallbacks are provided.

## Included areas
- Hero and AI-guidance visual concept
- Practice destination filters and route preview
- Company brand strip
- Company journeys, entrance exams, package, coding, aptitude, and mock interview paths
- Question bank filters, question previews, and code-editor preview
- Student leaderboard and ranking preview
- Bronze, Silver, Gold, Platinum, and Super Dream Pack pricing cards
- Daily practice checklist with progress tracking
- Feature overview, placement-level map, and level selection
- Assessment integrity command-center concept
- Student / HOD / Admin audience tabs
- Testimonials, FAQs, CTA, and multi-column footer

## Important prototype notes
- This is a front-end redesign, not a replacement backend. Question results, pricing, leaderboard values, and dashboard metrics are representative UI data.
- Security/assessment integrity panel is a visual concept, not a live proctoring system.
- The reference screenshot shows plan pricing; verify current prices and all company-approved wording before publishing.
- Connect real authentication, question-bank APIs, coding execution, payment, analytics, and institutional data before production.
